# ADR-001: Obsidian as the knowledge store

Status: Accepted

## Context

The knowledge base previously lived in Notion. Notion requires an ongoing subscription, imposes API limits and cannot be extended with bespoke tablet interactions.

## Decision

Use an Obsidian vault as the core knowledge store instead of Notion.

## Consequences

1. Notes are plain markdown files, enabling a self-hosted vault later.
2. Bespoke tablet interactions can ship as Obsidian plugins.
3. The Notion subscription and API limits are removed.
